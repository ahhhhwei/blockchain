# 以太坊概述

比特币是区块链1.0，以太坊是区块链2.0，以太坊在设计过程中针对比特币在运行过程中出现的一些问题做出了改进：

|   特点   | 比特币（Bitcoin）  |  以太坊（Ethereum）  |
| :------: | :----------------: | :------------------: |
| **目标** | 数字货币、价值存储 |  智能合约、dApp平台  |
| **功能** |      交易记录      |  智能合约和应用开发  |
| **编程** |     非图灵完备     | 图灵完备（Solidity） |
| **共识** |        PoW         |  PoS（以太坊2.0后）  |
| **供应** |   总量固定2100万   |      无总量限制      |
| **速度** |   区块时间10分钟   |     区块时间15秒     |
